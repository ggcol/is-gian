# Welcome to the Blog

This is an example article showing the frontmatter format and markdown rendering.

## How It Works

Articles are stored in individual folders within `src/content/blog/`. Each article has:

- **index.md** - The article content with frontmatter
- **Images** - Optional images stored alongside the article

## Frontmatter Format

```yaml
---
title: "Article Title" (required)
date: "YYYY-MM-DD" (required)
tags: ["tag1", "tag2"] (optional, for filtering)
excerpt: "Short description" (optional, shown in cards)
coverImage: "filename.jpg" (optional, relative to article folder)
---
```

## Markdown Features

You can use all standard markdown:

- **Bold** and *italic* text
- Lists (like this one)
- Code blocks
- Links and images
- And more!

Replace this example with your own articles!
